# 소셜 로그인 (OAuth 2.0) 설정 및 키 관리 가이드

본 문서는 터잡이 서비스의 소셜 로그인(카카오, 네이버, 구글) 기능 연동을 위해 각 플랫폼의 개발자 센터에서 앱을 등록하고 API 키를 발급받는 과정과, 이를 로컬 개발 환경 및 운영 배포 환경에서 어떻게 관리해야 하는지 기록한 문서입니다.

## 1. 애플리케이션 등록 관리 전략 (로컬 vs 운영)

개발 환경(`http://localhost:3001` 등)과 운영 환경(`https://www.teojabi.com` 등) 간의 접속 주소(Redirect URI) 충돌과 보안을 관리하기 위해 다음 두 가지 방법 중 하나를 선택하여 진행할 수 있습니다.

### 방법 1 (간편한 방법): 단일 앱에 주소 추가
하나의 애플리케이션(카카오/네이버/구글) 설정에 "로컬 주소"와 "운영 주소"를 모두 등록하여 사용하는 방식입니다.

*   **장점:** 관리가 편하고 하나의 API 키(Client ID/Secret)만 사용하면 됩니다.
*   **단점:** 실제 서비스 중에 개발용 컴퓨터(localhost)에서 테스트하다가 실수로 설정을 잘못 건드리면 실제 서비스 사용자들의 로그인도 일시적으로 중단될 위험이 있습니다.

### 방법 2 (권장 방법): 개발용 앱 / 운영용 앱 분리
각 플랫폼 개발자 센터에서 아예 새로운 애플리케이션을 하나 더 생성하여 환경을 원천 분리하는 방식입니다. (예: `터잡이 (개발용)`, `터잡이 (운영용)`)

*   **설정 방식:**
    *   **운영용 앱**: `https://www.teojabi.com` 관련 주소들만 등록. 발급된 키 값은 깃허브의 **GitHub Secrets**에 안전하게 보관하여 CI/CD 배포 시 서버에 주입되도록 합니다.
    *   **개발용 앱**: `http://localhost:3000`, `http://localhost:3001` 관련 주소들만 등록. 발급된 키 값은 개발자 PC의 로컬 `.env` 파일에 기록하여 사용합니다 (`.gitignore`로 인해 커밋되지 않음).
*   **장점:** 개발 중에 마음껏 테스트하거나 설정을 바꿔도 실제 서비스에는 전혀 영향을 주지 않아 안전합니다. 통계나 접속 에러 로그도 분리되어 트러블슈팅에 유리합니다.
*   **단점:** 초기 셋업 시 각 플랫폼마다 앱을 두 번씩 등록해야 하므로 설정해야 할 양이 많아집니다.

## 2. 플랫폼별 소셜 로그인 키 발급 가이드

아래 과정은 "방법 2"를 권장 기준으로 작성되었으나, "방법 1"을 선택할 경우 입력창에 줄바꿈으로 주소들을 추가 기입하기만 하면 됩니다.

### 🟡 카카오 (Kakao)

💡 카카오 디벨로퍼스가 최근(2025년 12월) 대규모 개편되면서 설정 메뉴 위치가 기존과 크게 달라졌습니다. 아래 개편된 최신 화면 UI 트리에 맞춘 가이드입니다.

1. **로그인 및 앱 생성**: [카카오 디벨로퍼스](https://developers.kakao.com/) 접속 -> **[내 애플리케이션]** -> **[애플리케이션 추가하기]** 클릭 (이름: 터잡이)
2. **키 복사 (.env 저장)**: 생성된 앱 클릭 후, 좌측 메뉴 **[앱] -> [플랫폼 키]** 선택. 화면 우측 목록에서 **[REST API 키]**의 `키 값`을 복사하여 `.env` 파일의 `KAKAO_CLIENT_ID`에 넣습니다.
3. **Web 플랫폼 (사이트 도메인) 등록**:
   - 좌측 메뉴 **[앱] -> [플랫폼 키]** 화면에서 **[JavaScript 키]** 항목을 클릭 (또는 우측 설정 버튼).
   - 하단의 **[사이트 도메인]** 등록 항목에서 `http://localhost:3000`과 `http://localhost:3001`을 각각 줄바꿈으로 입력하고 저장합니다.
4. **Redirect URI 등록 (REST API 키 설정)**:
   - 메뉴 **[앱] -> [플랫폼 키]** 화면에서 **[REST API 키]** 항목 클릭.
   - 하단의 **[리다이렉트 URI]** 등록 항목에서 `http://localhost:3001/api/v1/auth/kakao/callback`을 입력하고 저장합니다.
5. **카카오 로그인 기능 통째로 활성화**:
   - 좌측 메뉴 **[제품 설정] -> [카카오 로그인]** 클릭
   - 화면 상단의 **[활성화 설정]** 상태를 **[ON]** 으로 켭니다.
6. **Client Secret 확인 (보안 강화)**:
   - 좌측 메뉴 **[앱] -> [플랫폼 키]** 화면에서 **[REST 무빙 키]** 항목을 클릭합니다.
   - 하단의 보안 설정 항목에서 **[Client Secret]** 값을 복사하여 `.env`의 `KAKAO_CLIENT_SECRET`에 넣습니다. (새로운 개편에서는 자동으로 활성화되어 있습니다.)
7. **동의항목 설정**:
   - 좌측 메뉴 **[제품 설정] -> [카카오 로그인] -> [동의항목]** 클릭
   - 프로필 정보(닉네임/사진), 카카오계정(이메일) 등을 **[필수 동의]** 로 설정하고 저장합니다.

### 🟢 네이버 (Naver)

1. **접속**: [네이버 디벨로퍼스](https://developers.naver.com/)
2. **앱 생성**: [Application] -> [애플리케이션 등록] (이름: 터잡이)
3. **환경 설정**:
   - 사용 API: **[네이버 로그인]** 선택 (이름, 이메일 [필수] 체크)
   - 환경 추가: **[PC 웹]**
   - 서비스 URL: `http://localhost:3000`
   - Callback URL: `http://localhost:3001/api/v1/auth/naver/callback` (최대 5개 줄바꿈 등록 가능)
4. **키 복사 (.env 저장)**: 완료 화면에 나타나는 **Client ID** 값을 `NAVER_CLIENT_ID`로, **Client Secret** 값을 `NAVER_CLIENT_SECRET`로 사용

### 🔵 구글 (Google)

💡 2024~2025년에 걸쳐 구글 클라우드 콘솔의 OAuth 메뉴가 대대적으로 개편되었습니다. 기존 'API 및 서비스' 메뉴 대신 전용 **Google Auth Platform** 메뉴를 사용합니다.

1. **접속 및 프로젝트 생성**: [구글 클라우드 콘솔](https://console.cloud.google.com/) 접속 -> 최상단 프로젝트 선택 바에서 **[새 프로젝트]** 클릭 (이름: Teojabi)
2. **OAuth 동의 화면 (현: 브랜딩/Branding) 구성**:
   - 좌측 햄버거 메뉴(☰) 클릭 -> **[Google Auth Platform]** 메뉴 클릭 (기존 'OAuth 동의 화면' 메뉴가 없어지고 이 메뉴로 통폐합되었습니다.)
   - 하위 메뉴 중 **[브랜딩(Branding)]** 또는 **[개요(Overview) -> 시작하기]**를 클릭합니다.
   - User Type: **외부(External)** 선택
   - 앱 이름(터잡이) 및 지원 사용자 이메일 기입 후 저장.
   - 구성 완료 후 반드시 개요 탭 등에서 **[인증(Publish)]** 또는 **[앱 게시]**를 눌러 "테스트" 상태를 "프로덕션" 상태로 변경해야 오류 없이 정상 로그인 가능.
3. **클라이언트 ID 및 비밀번호 생성**:
   - 좌측 메뉴 **[Google Auth Platform] -> [클라이언트 (Clients)]** 클릭
   - 상단 **[클라이언트 만들기 (Create Client)]** 클릭 -> 애플리케이션 유형: **웹 애플리케이션** 선택
   - **승인된 자바스크립트 원본**: `http://localhost:3000` 추가
   - **승인된 리디렉션 URI**: `http://localhost:3001/api/v1/auth/google/callback` 추가
   - **[만들기]** 클릭
4. **키 복사 (.env 저장)**: 생성 직후 팝업되거나, 클라이언트 위젯을 클릭하면 우측 탭에 나타나는 **클라이언트 ID**와 **클라이언트 비밀번호(Secret)** 값을 복사하여 `.env` 파일의 `GOOGLE_CLIENT_ID`와 `GOOGLE_CLIENT_SECRET`에 넣습니다. (보안상 뒷자리만 보인다면 복사 아이콘을 눌러 전체를 복사합니다.)
