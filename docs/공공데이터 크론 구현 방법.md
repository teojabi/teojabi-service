# 공공데이터 정기 업데이트(Cron) 구현 가이드

이 문서는 서울시 건축물대장과 같은 대량의 공공데이터를 백엔드 서비스(NestJS)에서 권한 문제 없이 고속으로 임포트하기 위한 구현 계획을 담고 있습니다.

## 1. 핵심 전략: `psql \copy` 명령어 활용
PostgreSQL의 `COPY` 명령어는 서버 권한(`pg_read_server_files`)이 필요하지만, 클라이언트 명령어인 `\copy`를 사용하면 일반 사용자 권한으로도 로컬 파일을 고속으로 임포트할 수 있습니다. 백엔드 서비스에서 `child_process`를 통해 시스템의 `psql` 도구를 호출하는 방식을 채택합니다.

## 2. 사전 준비 사항
- **psql 설치**: 백엔드 서버 환경에 `psql` 클라이언트가 설치되어 있어야 합니다.
- **환경 변수**: DB 접속 정보(Host, User, DB Name, Password)가 `.env`에 설정되어 있어야 합니다.
- **파일 경로**: 임포트할 CSV 파일이 백엔드 서비스가 접근 가능한 위치에 있어야 합니다.

## 3. 단계별 구현 계획

### 1단계: psql 실행 유틸리티 구현
Node.js의 `child_process`를 사용하여 `\copy` 명령을 실행하는 로직을 작성합니다.

```typescript
import { exec } from 'child_process';
import { promisify } from 'util';
const execPromise = promisify(exec);

async function runPsqlCopy(filePath: string, tableName: string) {
  // PGPASSWORD 환경 변수를 사용하여 자동 인증 수행
  const command = `psql -h ${host} -U ${user} -d ${database} -c "\\copy ${tableName} FROM '${filePath}' WITH (FORMAT CSV, HEADER, ENCODING 'UTF8', NULL '')"`;
  
  try {
    const { stdout, stderr } = await execPromise(command, {
      env: { ...process.env, PGPASSWORD: process.env.DATABASE_PASSWORD }
    });
    console.log(`[Success] ${tableName}: ${stdout}`);
  } catch (error) {
    console.error(`[Error] ${tableName}: ${error.message}`);
  }
}
```

### 2단계: 스케줄러 서비스 작성
`@nestjs/schedule` 모듈을 사용하여 정기적인 실행 주기를 설정합니다.

```typescript
import { Injectable } from '@nestjs/common';
import { Cron, CronExpression } from '@nestjs/schedule';

@Injectable()
export class PublicDataScheduler {
  @Cron(CronExpression.EVERY_WEEKEND) // 매주 주말 실행
  async syncBuildingData() {
    const infoFile = 'database/서울시 건축물대장 표제부 utf-8.csv';
    const floorFile = 'database/서울시 건축물대장 층별개요.csv';

    await runPsqlCopy(infoFile, 'BuildingInfo');
    await runPsqlCopy(floorFile, 'BuildingFloor');
  }
}
```

### 3단계: 인프라 설정 (Docker 등)
Docker를 사용하는 경우, `Dockerfile`에 `postgresql-client` 설치 과정을 추가해야 합니다.
```dockerfile
RUN apt-get update && apt-get install -y postgresql-client
```

## 4. 기대 효과
- **성능**: 수십만 건의 데이터를 수 초 이내에 처리 가능 (일반 INSERT 대비 수백 배 빠름).
- **보안/권한**: DB 서버의 특수 권한 없이 일반 계정으로 안전하게 수행.
- **유연성**: 파일의 위치나 포맷 변경에 유연하게 대응 가능.
